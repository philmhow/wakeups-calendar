# WakeUps: Oilfield Calendar — public site

This repository exists for one reason: **Google Play requires a privacy
policy at a publicly reachable URL**, and the app's own repository is
private and stays private.

It contains no source code. Only the policy.

**Published at:** https://philmhow.github.io/wakeups-calendar/

## This is a copy, not the original

`index.md` is a copy of `store/privacy-policy.md` in the private application
repository (`wakeups-calendar`), which is the source of truth. When the
policy changes there, copy it here and push — the two silently drifting
apart is the one failure this repository can have, and it matters because
the copy here is the one users and Play reviewers actually read.

The date at the top of the policy is how to tell whether that has happened.
